# The Movie List — Live Calls

Independent caller and host dashboard for The Movie List.

- Public GitHub Pages site: https://the-movie-list-live.github.io/calls/
- Host dashboard: open the site and choose **Open host dashboard**.
- Caller link: generated by the host dashboard; share it with viewers.
- Supports up to two callers, host mute/deafen and volume controls, and caller audio routing.
- Uses PeerJS 1.5.5 for browser-to-browser calling.
